# Game log schema (schemaVersion 1)

One JSON file per game, written to `games/<name>.json` (gitignored). This is the
contract for anything that reads logs: replay page, stats, clip finder. The
TypeScript source of truth is `src/engine/types.ts` (`GameLog`). A sample is
regenerated by a test at `tests/fixtures/sample-game.json`.

Rules for readers:

- Check `schemaVersion` first. Any breaking change bumps it.
- Logs hold **no timestamps**, so the same seed and the same raw replies give a byte-identical file.
- Names are unique and act as player ids.
- `private_notes` exist only in `turns`. They are shown to viewers, never to players.

## Top level

| Field | Type | Meaning |
|---|---|---|
| `schemaVersion` | `1` | Schema version. |
| `seed` | integer | Seed for the game RNG (roles, speaking order, tie-breaks). |
| `settings` | `Settings` | Game settings used. |
| `cast` | `CastMember[]` | The players in seating order. |
| `roles` | `{ [name: string]: "traitor" \| "faithful" }` | Roles at the start. A recruit changes later; see `result.survivors` and `recruit` events. |
| `systemPrompt` | string | System prompt sent with every attempt of every turn. |
| `turns` | `Turn[]` | Every player turn, in order. `turns[i].id === i`. |
| `events` | `Event[]` | What happened in the game, in order. |
| `result` | `Result` | How it ended. |

### Settings

| Field | Type | Meaning |
|---|---|---|
| `maxRounds` | integer | The game ends after this many rounds (default 6). |
| `traitors` | integer | Number of traitors at the start (2). |

### CastMember

| Field | Type | Meaning |
|---|---|---|
| `name` | string | Player name. |
| `model` | string | OpenRouter model ID. `"mock"` for mock players, and `"human"` for a person playing a seat in the browser (see `?mode=play`). A human seat's `private_notes` are what the person typed in the optional note field. |

### Result

| Field | Type | Meaning |
|---|---|---|
| `winner` | `"traitor" \| "faithful" \| null` | Traitors win if any traitor is alive at the end. `null` only when `reason` is `cost_cap`. |
| `reason` | `"no_traitors" \| "no_faithfuls" \| "two_remaining" \| "endgame_vote" \| "max_rounds" \| "cost_cap"` | Why it ended. `cost_cap` means the game was stopped early by the cost cap. |
| `rounds` | integer | Rounds played (the last round may be partial). |
| `survivors` | `{ name: string, role: "traitor" \| "faithful" }[]` | Players alive at the end, with their final role. |
| `costCap` | `{ maxUsd: number, spentUsd: number }` (optional) | Present only when `reason` is `cost_cap`: the cap and what had been spent. |

## Turn

One call to a player for one decision, with the retry and fallback record.

| Field | Type | Meaning |
|---|---|---|
| `id` | integer | Position in `turns`, from 0. |
| `round` | integer | Round number, from 1. |
| `phase` | Phase | One of `night`, `whispers`, `round_table`, `vote`, `revote`, `recruit_choose`, `recruit_respond`, `endgame_vote`. |
| `player` | string | Who acted. |
| `attempts` | `Attempt[]` | 1 or 2 entries. A second entry is the single retry. |
| `speech` | string | Public speech from the accepted reply. Only `round_table` speech is shown to other players. `""` if there was none or on fallback. |
| `private_notes` | string | The player's stated strategy for this turn. `""` on fallback. |
| `action` | Action | The accepted action, or the fallback action. |
| `fallback` | boolean | `true` if no valid reply was obtained and a deterministic fallback action was used. |

A game stopped by the cost cap ends mid-round. Before each model call the engine
checks whether spend so far plus the dearest single call so far would pass the cap;
if so it stops before the call. If that happens before a retry, the turn is settled
with its fallback (`fallback: true`, one attempt) and the next turn stops the game.

The cap is a prediction, not a hard ceiling: the first call, or a call dearer than any
before it, can overshoot, and `costCap.spentUsd` can then be above `maxUsd`. A call with
no reported cost counts as free. To replay a capped log, pass the same cap
(`costCap.maxUsd`) as well as the same seed; without it the replay runs past the logged replies.

Night turns happen twice in a round when traitors disagree: the second set of
`night` turns is the single re-proposal.

### Attempt

| Field | Type | Meaning |
|---|---|---|
| `prompt` | string | Exact user prompt sent. On a retry it is the first prompt plus the error. |
| `raw` | string \| null | Raw reply text exactly as returned. `null` if the player threw (timeout, HTTP error); then `error` is the thrown message. |
| `extracted` | `true` (optional) | Present only when the reply had text around a single JSON object and the object was taken from it. Absent otherwise. |
| `usage` | `Usage` (optional) | What the provider reported for this call. Absent for mock players, thrown errors, and providers that report nothing. |
| `error` | string \| null | Why the attempt was rejected, or `null` if it was accepted. The accepted attempt is always last and has `error: null`; on fallback both attempts have an error. |

### Usage

All fields optional; a field is present only if the provider returned it.

| Field | Type | Meaning |
|---|---|---|
| `promptTokens` | number | Input tokens. |
| `completionTokens` | number | Output tokens. |
| `totalTokens` | number | Input plus output tokens. |
| `costUsd` | number | Cost of the call in USD, when the provider reports it. |

### Action by phase

| Phase | Action | Notes |
|---|---|---|
| `night` | `{ target: string }` | A living faithful. |
| `whispers` | `{ to: string \| null, message: string }` | `to: null` sends nothing (`message` is `""`). |
| `round_table` | `{ suspect: string, reason: string }` | A living player other than the speaker. `reason` is `""` on fallback. |
| `vote` | `{ target: string }` | A living player other than the voter. |
| `revote` | `{ target: string }` | One of the tied players other than the voter. |
| `recruit_choose` | `{ target: string \| null }` | A living faithful, or `null` for no offer. |
| `recruit_respond` | `{ accept: boolean }` | |
| `endgame_vote` | `{ choice: "end" \| "banish" }` | |

Fallback actions are deterministic: a target is `options[turnId % options.length]`,
a whisper is `{to: null}`, no recruit offer, a refusal, and `"banish"`.

## Event

Every event has these fields, plus the type-specific ones below.

| Field | Type | Meaning |
|---|---|---|
| `type` | string | Event type. |
| `round` | integer | Round number. |
| `afterTurn` | integer | `id` of the last turn logged before this event, or `-1`. Merge events into the turn list by this. |
| `visibleTo` | `"all" \| string[]` | Who could see this in their prompts. |

| `type` | Extra fields | `visibleTo` | Meaning |
|---|---|---|---|
| `murder` | `victim: string \| null`, `proposals: {player: string, target: string}[]`, `method: "agreed" \| "random" \| "none"` | the traitors | The night result. `proposals` are the final proposals. `random` means they still disagreed after the second proposal and one proposal was picked at random (seeded). `none` means no victim was possible. |
| `breakfast` | `victim: string \| null`, `role: "traitor" \| "faithful" \| null` | all | The reveal. |
| `whisper` | `from: string`, `to: string`, `message: string` | `[from, to]` | A delivered whisper. Logged after all whisper turns of the round. |
| `speech` | `player: string`, `speech: string`, `suspect: string`, `reason: string` | all | A round table statement. |
| `vote` | `stage: "vote" \| "revote"`, `votes: {voter: string, target: string}[]`, `tally: {[name: string]: number}`, `leaders: string[]` | all | One round of voting. `tally` omits players with 0 votes. More than one `leaders` entry means a tie. |
| `banishment` | `player: string`, `role: "traitor" \| "faithful"`, `method: "majority" \| "revote" \| "random"` | all | Who was banished and how the tie, if any, was settled. |
| `recruit` | `offeredBy: string`, `offeredTo: string`, `accepted: boolean` | `[offeredBy, offeredTo]` | A recruitment offer and the answer. If `accepted`, `offeredTo` is a traitor from now on. Not logged when no offer was made. |
| `endgame_vote` | `votes: {voter: string, choice: "end" \| "banish"}[]`, `end: boolean` | all | The end-or-banish vote. `end` is true on a strict majority for `"end"`. |

## Ordering inside a round

`night` turns → `murder` → `breakfast` → `whispers` turns → `whisper` events →
`round_table` turns, each followed by its `speech` event → `vote` turns →
`vote` event → (`revote` turns → `vote` event) → `banishment` → (`recruit_choose`,
`recruit_respond` turns → `recruit` event) → (`endgame_vote` turns → `endgame_vote`
event). Use `afterTurn` rather than relying on this order.
